# 提示词生成模型训练

用 QLoRA 微调 Qwen3-4B，让模型把用户的一句简述改写成结构清晰、约束明确、可直接执行的提示词。

---

## 1. 目标

输入：`做个记账的`（用户的一句大白话）

输出：

```
帮我做一个简单的记账工具：能记录每天的每一笔收入和支出，每笔要写清金额、日期和用途；
按吃饭、交通、购物、房租等类别自动归类；月底能看出这个月一共花了多少、哪一类花得最多。
```

核心是**把用户没说但重要的信息补上**：内容要素、体裁、长度、语气、格式。

---

## 2. 数据

### 2.1 来源

| 数据集 | 规模 | 字段 | 特点 |
|---|---|---|---|
| `prompt-refinement-dataset` | 1,561 → 清洗后 1,353 | `input` → `output` | 杂乱原文 → 结构化提示词，风格为「角色 + 约束 + 格式」 |
| `MePO` | 40,151 → 清洗后 32,336 | `raw_prompt` → `chosen` | 简述 → 精炼提示词，附 `chosen`/`rejected` 偏好对 |

### 2.2 清洗要点

两个数据集都有共同的污染模式，清洗规则是**先量化再定规则**，不凭直觉：

| 问题 | 规模 | 处理 |
|---|---|---|
| 输出被引号包裹 | refinement 288 条 | 去掉外围引号 |
| 输出带 `Here's an improved version...` 开场白 | refinement 185 条 | 正则剥离（必须覆盖 `Here's` 缩写，不能只写 `here is`） |
| 输出把「答案」写进提示词 | MePO 282 条 | 删除（会让模型直接答题而不是生成提示词） |
| RAG 样本（输入塞满搜索结果） | 21 条 | 删除 |
| 重复样本 | MePO 5,245 条 | 归一化去重 |

**一个反直觉的教训**：不能加「输出必须比输入长」这类比例过滤。两个数据集里都有大量合法样本的任务本身就是「缩短」，按比例过滤会误删上百条好数据。只保留一个绝对下限。

### 2.3 最终数据

| 目录 | train | val | test |
|---|---|---|---|
| `data/refinement/` | 1,353 | 75 | 75 |
| `data/mepo/` | 32,336 | 1,032 | 1,032 |

## 3. 训练

### 3.1 配置

| 项目 | 设置 |
|---|---|
| 基座 | Qwen3-4B-Instruct-2507 |
| 量化 | 4-bit NF4 + double quant |
| LoRA | r=16，alpha=32，dropout=0.05，覆盖 7 个线性层 |
| 序列长度 | 768（refinement）/ 384（MePO） |
| 学习率 | 1e-4（首轮）/ 5e-5（增量） |
| batch | 1 × grad_accum 16 |
| 优化器 | paged_adamw_8bit |
| loss | 只在 assistant 段计算（`assistant_only_loss`） |
| 精度 | bfloat16 |

### 3.2 两轮训练

| 轮次 | 数据 | 耗时 | train loss | eval loss |
|---|---|---|---|---|
| 第一轮 | refinement 1,353 | 249 步 / 45 分钟 | 2.055 → 0.758 | 0.984 → 0.928 |
| 第二轮 | MePO 32,336（增量） | 775 步后停止 | — | 0.880 → 0.770 |

第二轮用**增量训练**：从第一轮的 adapter 继续训，而不是从基座新建。

### 3.3 关键工程细节

**`assistant_only_loss=True` 必须开。** 否则模型会花大量算力学复述用户输入。

**`max_length` 的命名**：TRL 1.14 用 `max_length`，不是 `max_seq_length`（写旧名会静默失效）。

**显存缓存池管理**：PyTorch 的显存缓存池只增不减，长时间训练会逼近显存上限，之后每次分配都要先驱逐旧块，速度掉一个数量级。在优化器 step 后调用 `torch.cuda.empty_cache()` 可解决，实测训练速度提升 3.4 倍（24 分钟 → 7 分钟）。

## 4. 训练得到的两个模型

| 模型 | 路径 | 能力 |
|---|---|---|
| 第一轮 | `runs/refinement/final` | 详细结构化：角色 + 约束 + 字数 + 格式 |
| 第二轮 | `runs/mepo/checkpoint-700` | 精准精炼：几乎逐词贴合参考提示词 |

**第一轮是 SPIN 优化的起点**（见 `02-SPIN优化.md`）。

## 5. 复现

```bash
conda activate spin
export HF_HUB_OFFLINE=1

# 数据清洗
python src/prep_refinement.py      # -> data/refinement/
python src/prep_mepo.py            # -> data/mepo/

# 第一轮训练
python src/train_sft.py train --data refinement

# 第二轮增量训练
python src/train_sft.py train --data mepo --init_adapter runs/refinement/final

# 训练监控
python src/check_training.py mepo 2020
```
