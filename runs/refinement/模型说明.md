# 第一轮训练输出

在 `prompt-refinement-dataset`（清洗后 1,353 条）上做 QLoRA 训练的输出目录。

| 项目 | 说明 |
|---|---|
| 数据 | `data/refinement/`，1,353 条训练对 |
| 训练配置 | LoRA r=16 / alpha=32，序列长度 768，学习率 1e-4，3 epoch |
| 训练步数 | 249 步 |
| 损失变化 | train 2.055 → 0.758，eval 0.984 → 0.928 |
| 耗时 | 约 45 分钟 |

训练完成后得到的能力：**详细结构化**——输出包含角色设定、约束条件、字数限制和格式要求。

本目录下 `final/` 是可直接使用的 adapter，也是后续 SPIN 优化的起点。
