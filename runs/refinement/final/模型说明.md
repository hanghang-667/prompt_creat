# 第一轮模型：详细结构化提示词

在 `prompt-refinement-dataset` 上 QLoRA 训练得到的 LoRA adapter。

**这是本项目的训练起点模型，也是 SPIN 优化的起点。**

## 能力特点

把简述改写成包含以下要素的详细提示词：

- 角色设定（如「作为一位资深…」）
- 明确的约束条件（数量、范围、必须包含的内容）
- 字数或篇幅限制
- 输出格式要求（分点、表格、结构化）

## 使用

```bash
python src/spin_train.py explain --init runs/refinement/final --n 3
```

服务端加载：

```bash
python app/serve.py --adapter runs/refinement/final
```
