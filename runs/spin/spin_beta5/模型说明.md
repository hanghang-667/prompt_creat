# SPIN 优化输出（最终交付模型）

用 SPIN 自博弈微调优化后的模型，**本项目的最终交付物**。

| 项目 | 说明 |
|---|---|
| 起点 | `runs/refinement/final` |
| 训练数据 | MePO 抽样 200 条（只需简述与参考提示词） |
| 配置 | β=5.0，学习率 1e-5，3 epoch，序列长度 384 |
| 训练步数 | 75 步 |
| 耗时 | 约 7 分钟 |

## 为什么选 β=5.0

β 控制 SPIN 目标的保守程度。实测 β=0.1（论文默认）在本任务上会**过优化**：损失被压到 0.003、logit 冲到 +58，等于把模型自身输出的概率压垮，通用能力随之崩溃。β=5.0 让目标在 logit≈3 处饱和，给出最好的权衡。

## 效果

| 指标 | 起点模型 | 本模型 |
|---|---|---|
| 目标能力损失 | 2.4054 | 2.3656 |
| 保持能力结构分 | 1.80 | **2.00** |

在目标、保持、中文三类生成指标上全面不劣于起点，保持能力反而更好；且在同目标提升水平上严格优于直接 SFT 对照。

## 使用

```bash
python app/serve.py --adapter runs/spin/spin_beta5/policy
```

服务端默认加载本模型。
