# SPIN 实验输出目录

自博弈微调（SPIN）的全部实验产物。

| 子目录/文件 | 内容 |
|---|---|
| `spin_beta5/` | **最终交付模型**（β=5.0） |
| `records/` | 各方法的评测记录（target_loss、retain_loss、逐条生成） |
| `对照结果.md` | 全方法量化对照表 + 逐条输出并排对比 |
| `pairs_iter0.jsonl` | 第一轮生成的训练对（含缓存的对手 log-概率） |
| `pairs_iter1.jsonl` | 第二轮生成的训练对 |

完整的实验设计、七组对照与结论见 `docs/02-SPIN优化.md`。
